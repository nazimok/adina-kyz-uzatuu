АДИНА | КЫЗ УЗАТУУ — ВЕРСИЯ 1.1

Файлдар:
- index.html: сайттын түзүлүшү жана кыргызча тексттери
- styles.css: бордовый, алтын жана сүт түстүү дизайн, конверттин стили
- script.js: конвертти ачуу, меню, санак, тесттик анкета
- assets/adina-floral-background.png: негизги гүлдүү фон

Иштетүү:
1. ZIP архивди толугу менен чыгарыңыз.
2. Папканы VS Code менен ачыңыз.
3. index.html файлын Live Server аркылуу иштетиңиз.

Жаңыртуулар:
- Сайт эми конверттин экраны менен ачылат. "ЧАКЫРУУНУ АЧУУ" басылганда конверт ачылып, негизги сайт көрүнөт.
- Башкы экрандагы бош борбордук орунга текстти камтыган тунук кооз рамка кошулду.
- Блоктордун ортосуна майда алтын түстүү орнаменттер кошулуп, фон өтмөктөрү жумшартылды.
- Дата: script.js ичиндеги EVENT_DATE маанисин кийин толтуруңуз.
- Дарек жана убакыт: index.html ичиндеги "Жакында жарыяланат" тексттерин алмаштырыңыз.
- Telegram азырынча кошулган жок. Анкета тесттик билдирүү гана көрсөтөт.
